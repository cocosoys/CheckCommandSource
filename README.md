# CheckCommandSource
该插件允许你检查命令的来源，比如health, fps, back等。

提供指令:

/checkcommandsource [指令名称]

例如:/checkcommandsource checkcommandsource

输出示例:

```text
[16:04:54 INFO]: 指令来自: CheckCommandSource
[16:04:54 INFO]: 插件文件路径: /D:/MyGame/Minecraft/Server/Craftbukkit/1.12.2/Craftbukkit-1.12.2-Latest/plugins/checkcommandsource-1.0-SNAPSHOT.jar
```

若你遇到问题，重复一次你所发现的问题，并将后台输出数据发送给作者。
